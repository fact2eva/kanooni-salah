### Step 1: Create a Repository on GitHub

1. Go to [GitHub.com](https://github.com) and create a **New repository**.
2. Name it (e.g., `kanooni-salah` or `your-username.github.io`).
3. Set visibility to **Public** (GitHub Pages is free for public repositories).
4. Do not initialize with README (we already have all files ready).

```bash

git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

*(Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your actual GitHub details).*

---

### Step 3: Turn On GitHub Pages

1. In your GitHub repository, click **Settings**.
2. In the left menu, click **Pages** (under *Code and automation*).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main`
   - **Folder**: Select `/ (root)`
4. Click **Save**.

Within 30–60 seconds, your site is live!
