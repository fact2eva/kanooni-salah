## 🚀 Easy 1-Minute Hosting on GitHub Pages (Zero-Build)

1. **Push your code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for Kanooni Salah website"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
   git push -u origin main
   ```

2. **Turn On GitHub Pages**:
   - Go to your repository on GitHub → **Settings** → **Pages** (under *Code and automation*).
   - Under **Build and deployment** → **Source**, select **Deploy from a branch**.
   - Under **Branch**, select **`main`** and folder **`/ (root)`**.
   - Click **Save**.

🎉 **Your website is live forever for free at**: `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`
